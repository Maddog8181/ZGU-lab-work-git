# Учебный калькулятор — лабораторная работа №2

Небольшой проект на Python для изучения Git и GitHub. В истории репозитория показаны сохранение изменений, работа в отдельных ветках, два запроса на объединение и ручное разрешение конфликта.

## Возможности

- `add(a, b)` — сложение двух чисел.
- `multiply(a, b)` — умножение двух чисел.
- При запуске программа выводит приветствие и два подготовленных примера вычислений.

## Получение проекта и запуск

Нужны Git и Python 3. Дополнительные библиотеки не требуются.

```powershell
git clone https://github.com/Maddog8181/ZGU-lab-work-git.git
cd ZGU-lab-work-git
py src/main.py
```

В Linux и macOS вместо `py` обычно используется `python3`.

Результат запуска:

```text
Учебный калькулятор: сложение и умножение.
2 + 3 = 5
2 * 3 = 6
```

Функции можно вызвать с другими числами. Пример из корня проекта:

```powershell
py -c "from src.main import add, multiply; print(add(10, 5)); print(multiply(4, 7))"
```

Результат — `15` и `28`.

## Этапы работы с Git

| Этап | Результат |
|---|---|
| Начальная версия | Создан `src/main.py` с выводом `Hello, World!` |
| `feature-1` | Добавлено сложение; проверено и объединено через [запрос №1](https://github.com/Maddog8181/ZGU-lab-work-git/pull/1) |
| `feature-2` | Добавлено умножение и изменено приветствие |
| `hotfix` | Та же исходная строка приветствия изменена по-другому и включена в `main` |
| Конфликт | В `feature-2` вручную согласовано приветствие и сохранены обе функции; завершён [запрос №2](https://github.com/Maddog8181/ZGU-lab-work-git/pull/2) |
| Проверки | [Восемь проверок вычислений и успешный запуск программы](docs/verification.md) |

Исходные ветки сохранены для просмотра истории. Команда ниже показывает коммиты и их связи:

```powershell
git log --oneline --graph --decorate --all
```

## Почему возник конфликт

От одной исходной версии созданы две ветки. В обеих по-разному изменена строка `print("Hello, World!")`. После объединения `hotfix` с `main` Git не мог автоматически выбрать приветствие при включении `feature-2`.

Вручную выбран итоговый текст: `Учебный калькулятор: сложение и умножение.`. Решение сохранено отдельным коммитом, программа проверена, после чего второй запрос объединён.
