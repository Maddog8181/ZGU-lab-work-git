# StudyFlow — учебные задания и сроки

Консольный помощник для студента: записать задание, увидеть ближайший срок и отметить выполненную работу. Продолжает тему StudyFlow из первой лабораторной работы.

У задания есть название, предмет, дата сдачи и отметка выполнения. Программа хранит записи на компьютере между запусками.

## Быстро посмотреть пример

Нужен **Python 3.10 или новее**. Дополнительные библиотеки не требуются.

```powershell
git clone https://github.com/Maddog8181/ZGU-lab-work-git.git
cd ZGU-lab-work-git
py src/main.py
```

Без аргументов открывается демонстрационный список с датой **23.11.2026**. Дата фиксирована, чтобы пример просроченного задания оставался понятным при повторном показе. Демонстрация не создаёт и не меняет личные записи.

В Linux и macOS вместо `py` используй `python3`.

## Записать свои задания

Команды выполняются из папки проекта:

```powershell
py src/main.py add "Подготовить отчёт по Git" --subject "Информационные технологии" --due 2026-11-24
py src/main.py list
py src/main.py done 1
py src/main.py summary
```

`done 1` отмечает выполненным задание с номером 1. При добавлении программа сообщает номер новой записи. Для второго и следующих заданий используй их номера.

| Команда | Результат |
|---|---|
| `demo` или запуск без аргументов | Пример учебного списка без записи данных |
| `add` | Добавить задание с предметом и сроком |
| `list` | Показать задания по сроку сдачи |
| `done` | Отметить задание выполненным по номеру |
| `summary` | Посчитать все, выполненные, оставшиеся и просроченные задания |

**Правило срока:** задание просрочено, если его дата сдачи раньше сегодняшней и оно ещё не выполнено. Срок сегодня не считается просроченным. В работе со своими заданиями используется текущая дата компьютера.

Личные записи находятся в `localdata/tasks.json`. Этот каталог исключён из Git. Для отдельного списка можно задать другой файл; параметр ставится перед командой:

```powershell
py src/main.py --file localdata/practice.json add "Повторить команды Git" --subject "ИТ" --due 2026-11-25
py src/main.py --file localdata/practice.json list
```

Пустое название, неверная дата и неизвестный номер задания вызывают сообщение об ошибке. Повреждённый файл данных не заменяется пустым списком.

## Как устроен проект

```text
src/main.py              программа и обработка команд
data/example_tasks.json  демонстрационные задания
tests/test_main.py       проверки правил и сохранения записей
docs/git-history.md      выполненные этапы лабораторной по Git
docs/verification.md     результаты проверки программы
```

Проверить программу:

```powershell
py -m unittest discover -s tests -v
```
