## Что происходило при конфликте

Ветки `feature-2` и `hotfix` созданы от одной версии. Обе по-разному изменили строку приветствия в `src/main.py`. После включения `hotfix` в `main` второй запрос нельзя было объединить автоматически.

В `feature-2` выполнено объединение с `main`. Конфликтующий блок отредактирован вручную: выбран общий текст приветствия, удалены служебные отметки, сохранены обе арифметические функции. Восемь проверок прошли, после чего запрос №2 объединён.

Этот конфликт относится к ранней версии калькулятора. Его [итоговый код](https://github.com/Maddog8181/ZGU-lab-work-git/blob/v1.0.0/src/main.py) и [результаты проверок](https://github.com/Maddog8181/ZGU-lab-work-git/blob/v1.0.0/docs/verification.md) доступны по тегу `v1.0.0`. В текущем `main` находится StudyFlow.

## Развитие проекта

В ветке `feature-study-planner` калькулятор заменён помощником для учёбы: добавление записей, сортировка по датам, отметка выполнения, сводка просроченных заданий и сохранение в JSON. Изменение подготовлено отдельным запросом на объединение; ранние коммиты и тег не переписывались.

Просмотр истории:

```powershell
git log --oneline --graph --decorate --all
git show v1.0.0 --no-patch
```
