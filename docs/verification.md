# Проверка StudyFlow

Проверено 23.11.2026. Используется стандартный `unittest`, дополнительные библиотеки не нужны.

```powershell
py -m unittest discover -s tests -v
```

Результат: **11 тестов пройдены**.

| Проверка | Результат |
|---|---|
| Срок вчера, сегодня и завтра; выполненное задание с прошедшим сроком | Просрочено только невыполненное задание со сроком раньше сегодняшнего |
| Сводка пустого списка | Все счётчики равны нулю |
| Добавление нескольких заданий | Разные номера, пробелы по краям названия и предмета убраны |
| Пустые поля, невозможная дата и неправильный формат | Запись не добавляется |
| Добавление и выполнение между вызовами | Изменения сохраняются в JSON; повторная отметка не дублирует запись |
| Неизвестный номер | Сообщение об ошибке, сохранённый файл не меняется |
| Повреждённый JSON | Ошибка, исходный файл не перезаписывается |
| Запись без обязательных полей | Ошибка, исходный файл не перезаписывается |
| Неверная дата через команду добавления | Файл с заданиями не создаётся |
| Запуск демонстрации без аргументов | Личные данные не создаются; дата примера зафиксирована |
| Список на границе месяцев | Сортировка по сроку, ноябрь перед декабрём |

Отдельно проверены последовательные запуски программы в новом временном файле: `add`, `list`, `done`, `summary`. После выполнения одного задания получено `Всего: 1 | Готово: 1 | Осталось: 0 | Просрочено: 0`. Завершение неизвестного номера возвращает ошибку и не меняет файл.

## Демонстрационный пример

Команда `py src/main.py` использует учебные записи из `data/example_tasks.json` и дату 23.11.2026. Итог:

```text
Всего: 4 | Готово: 1 | Осталось: 3 | Просрочено: 1
```

Срок сегодняшнего задания не считается прошедшим. Выполненное задание также исключается из просрочки. Команды для личного списка используют текущую дату компьютера.

## Исторические проверки калькулятора

Восемь проверок сложения и умножения относятся к **v1.0.0**, а не к текущему StudyFlow. Их результаты и исходные команды сохранены [в документе той версии](https://github.com/Maddog8181/ZGU-lab-work-git/blob/v1.0.0/docs/verification.md). Для просмотра ранних запросов и решения конфликта используй [историю лабораторной](git-history.md). Исходные ветки, коммиты и тег v1.0.0 сохранены.

Проверки выполнены локально в рамках индивидуальной учебной работы; автоматическая проверка через GitHub Actions и одобрение другим участником не заявляются.
