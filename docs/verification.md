# Проверка учебного калькулятора

Проверки выполнены локально при подготовке лабораторной работы №2.

## Сложение перед первым объединением

Ветка `feature-1`, коммит `a46cb937f1dc1f5ce5952b8ea6f4024857801b1c`.

| Вызов | Ожидаемый результат | Полученный результат |
|---|---:|---:|
| `add(2, 3)` | 5 | 5 |
| `add(-2, 3)` | 1 | 1 |
| `add(0, 0)` | 0 | 0 |
| `add(1.5, 2.5)` | 4 | 4.0 |

Код просмотрен, четыре проверки пройдены. Результат включён в основную ветку через [запрос №1](https://github.com/Maddog8181/ZGU-lab-work-git/pull/1).

## Конфликт изменений

Обе ветки созданы от версии `0a9a05d27c6c302c8cda578835edb23337f3512f`.

- `feature-2` до решения: `5755dbc618207f9232ef62168331afbaf522ff9a`.
- `main` после включения `hotfix`: `5c72319935adeaf4d119aa25e61b07157ba4dc2b`.
- Коммит ручного решения: `ad45cf6a1dacf59f968ade748370f837fe4dea1b`.

В обеих ветках по-разному изменена одна исходная строка приветствия. GitHub показал предупреждение о конфликте и заблокировал кнопку объединения [запроса №2](https://github.com/Maddog8181/ZGU-lab-work-git/pull/2).

При локальном выполнении `git merge main` в ветке `feature-2` получено:

```text
CONFLICT (content): Merge conflict in src/main.py
Automatic merge failed; fix conflicts and then commit the result.
```

Решение: вместо двух вариантов оставлена строка `Учебный калькулятор: сложение и умножение.`. Служебные отметки конфликта удалены. Функции сложения и умножения сохранены. Результат добавлен командой `git add` и записан отдельным коммитом объединения.

## Проверка после решения конфликта

| Вызов | Ожидаемый результат | Полученный результат |
|---|---:|---:|
| `add(2, 3)` | 5 | 5 |
| `add(-2, 3)` | 1 | 1 |
| `add(0, 0)` | 0 | 0 |
| `add(1.5, 2.5)` | 4 | 4.0 |
| `multiply(2, 3)` | 6 | 6 |
| `multiply(-2, 3)` | -6 | -6 |
| `multiply(0, 5)` | 0 | 0 |
| `multiply(1.5, 2)` | 3 | 3.0 |

Все восемь проверок пройдены. Команда `git diff --check` ошибок не обнаружила.

Запуск `py src/main.py` вывел:

```text

2 + 3 = 5
2 * 3 = 6
```
